# alocacao-compramento-fio
## Descrição do Problema
Calcular o comprimento total de cabo necessário para conectar sensores em uma linha de produção, aplicando uma sobra de segurança de 10%.
## Requisitos
- Receber lista de distâncias entre sensores
- Somar as distâncias
- Aplicar margem de segurança
- Arredondar para cima
## Exemplo de Uso
Entrada: [2, 3, 5]
Saída: 12
